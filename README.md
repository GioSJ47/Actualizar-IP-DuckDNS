# Actualizar-IP-DuckDNS
Actualiza tu IP pública en el servicio DuckDNS

## Pasos para usar

### Configuración inicial
Primero ingresa en DuckDNS.org e inicia sesión con el método que prefieras.

Copia el token y pegarlo en el "Actualizador IP DuckDNS" eligiendo la opción "5. Agregar token".

### Configura un dominio
Con tu sesion iniciada en DuckDNS.org, verás que luego de "domains" puedes agregar un dominio deseado, ahí debes colocar el nombre de tu dominio y darle al boton que dice "add domain".

Tu nuevo dominio saldrá en el listado de abajo, puedes agregar hasta 5 dominios con el plan gratuito de DuckDNS.

Luego debes agregar ese mismo dominio en el "Actualizador IP DuckDNS" eligiendo la opción "3. Agregar dominio", a continuación solo ingresa el nombre del dominio sin colocar "duckdns.org" y listo. Para corroborar que el dominio se agregó correctamente, ingresa en la opcion "2. Ver dominios" y tu dominio agregado debería salir en el listado.

### Poner en funcionamiento
Una vez tengas ingreasado tu token y tus dominios correctamente, ya puedes iniciar "Actualizador IP DuckDNS" en modo actualizador de IP seleccionando la opción "1. Iniciar Actualizador", cuando el programa está en este modo, se encargará de actualizar autmaticamente tu IP cada vez que cambie de forma automática.
